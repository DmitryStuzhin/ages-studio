# Ages Studio — студия производства Illustrated Ages

Личная платформа для канала Illustrated Ages: от выбора роли до пакета видео и разбора после публикации. Мастер-промпт, уроки канала, сводка ниши и прошлые сценарии хранятся в базе и сами подставляются в каждый шаг — больше не нужно заново описывать контекст в чате.

## Установка на Mac с автообновлением

Платформа работает фоновой службой на `http://localhost:3000` и сама подтягивает изменения из GitHub каждые 5 минут.

```bash
git clone https://github.com/DmitryStuzhin/ages-studio.git ~/ages-studio
cd ~/ages-studio
cp ~/Desktop/forge/.env.local .          # ключи
cp -R ~/Desktop/forge/.data . 2>/dev/null # база, если уже есть данные
bash scripts/install-mac.sh
```

Папка — именно `~/ages-studio`, не рабочий стол: macOS не даёт фоновым службам доступ к Desktop и Documents.

- Обновить прямо сейчас: `bash scripts/ages-update.sh --force`
- Логи: `~/Library/Logs/ages-studio/` (`update.log`, `server.log`, `build.log`)
- Если новая версия не собралась, скрипт откатывается на предыдущую, и сервер продолжает работать.
- Удалить службы: `bash scripts/uninstall-mac.sh`

## Запуск для разработки

```bash
npm install
npm run dev          # http://localhost:3000
```

База поднимается сама: без `DATABASE_URL` используется встроенный PostgreSQL (PGlite) в папке `.data/`. Для своего Postgres:

```bash
cp .env.example .env.local
# DATABASE_URL=postgres://user:pass@localhost:5432/ages
```

Схема создаётся при первом запуске, мастер-промпт v8, библиотека драматургии, уроки из v7 и вышедшие ролики засеиваются автоматически. Сбросить всё: удалить `.data/`.

```bash
npm run build && npm start   # продакшен
npm test                     # тесты парсеров, гейтов и пакета
npm run typecheck
```

## Как работает конвейер

**Ролик:** 0 Выбор роли (необязательно) → 1 Параметры → 2 Разведка и база фактов → 3 Угол, хук, вердикт → 4 Журнал угроз и карта → 5 Персонажи → 6 Сценарий → 7 Аудит, факты, антишаблон → 8 Кадры и промпты → 9 Упаковка → 10 Пакет видео → 11 Разбор.

**Шортс:** Параметры → Отбор угроз → Хук и сценарий → Раскадровка 9:16 → Упаковка и график → Пакет.

В каждом шаге:
1. Платформа собирает промпт: конституция (кешируется) + инструкция шага + нужные блоки контекста из базы.
2. Ответ получается одним из трёх способов: **Сгенерировать** (Claude API), **Скопировать промпт** → чат Claude → **Вставить ответ**, или **Демо** (заглушка в правильном формате, чтобы проверить конвейер).
3. Код считает механические гейты: хронометраж по 155 сл/мин, длина реплик, запрещённые фразы, позиции ⚡/🔑/✖/☠ по выбранной структуре, окна без угрозы, счётчик 🛡, акценты на даты, совпадение озвучки, 16:9 и блок стиля в промптах, антишаблон против прошлых сценариев, чередование структур и хуков.
4. Ты правишь ответ прямо в окне и утверждаешь. С непройденным гейтом — только явной галочкой «под мою ответственность». Повторное утверждение раннего шага снимает утверждения следующих.

**Пакет видео** (zip): `manifest.json`, `timeline.fcpxml` (DaVinci Resolve / Final Cut / Premiere), `brief.md` для Claude Code, `subtitles.srt`, `voiceover_text.txt`, `prompts.txt`, `packaging.md`, `frames_check.json`. Комплектность кадров проверяется по именам файлов из выбранной папки — сами файлы никуда не загружаются.

**Петля улучшений:** разбор после публикации предлагает уроки и правки промпта. Уроки попадают в генерацию только после твоего «Принять»; правки промпта создают новую версию, старые версии остаются и активируются в один клик. Выводы об удержании — только при 100+ просмотрах из главной и рекомендаций.

## YouTube

1. В `.env.local` задай `YOUTUBE_API_KEY` — платформа сразу начнёт обновлять данные: при запуске и дальше каждые 12 часов (меняется в Настройках), плюс кнопка «Обновить данные» в Аналитике, Нише и Настройках.
   - подписчики канала → снимок на Пульте;
   - статистика всех роликов канала, автопривязка проектов к вышедшим роликам по названию (проект сам становится «опубликованным»);
   - сводка ниши по поисковым запросам из Настроек (≈ 500–1 000 единиц квоты за запуск из 10 000 в сутки).
2. Для удержания и часов задай `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`, перезапусти и нажми «Войти через Google» в Настройках. Redirect URI в Google Cloud: `http://localhost:3000/api/auth/google/callback`. После входа на 2, 7 и 28 день после выхода ролика сами появляются снимки метрик: просмотры, % досмотра, главная+рекомендации, Shorts, кривая удержания; и часы канала за 12 месяцев без Shorts. CTR показов YouTube Analytics API не отдаёт — его вносишь из Studio.

Если OAuth-приложение в режиме **Testing**, Google отзывает вход через 7 дней. Платформа предупреждает за 48 часов жёлтой плашкой, а после истечения показывает красную с кнопкой «Войти снова»; пропущенные снимки 2/7/28 дня досчитываются после входа. Твой email должен быть в Audience → Test users.

Расписание работает, пока платформа запущена; если компьютер был выключен, обновление пройдёт сразу после запуска.

## Интеграции

Все работают в ручном режиме, пока не задан ключ в `.env.local` (см. `.env.example`).

| Интеграция | Статус в коде | Что даст |
|---|---|---|
| Claude API | адаптер готов, нужен `ANTHROPIC_API_KEY` | кнопка «Сгенерировать», конституция с prompt caching |
| YouTube Data API | работает, нужен `YOUTUBE_API_KEY` | канал, ролики, сводка ниши каждые 12 ч и по кнопке |
| YouTube Analytics API | работает после входа через Google | метрики 2/7/28 дней, кривая удержания, трафик, часы |
| ElevenLabs | интерфейс | озвучка по сценам с таймкодами слов → точные тайминги манифеста |
| Google Drive | интерфейс, сейчас — выбор папки | автоматическая проверка кадров в папке проекта |

Модели по шагам: сценарий, разбор, угол, аудит — Opus 5.5; раскадровка, промпты, упаковка — Sonnet 5.5; рутина — Haiku 5.5. Оценка стоимости видна в каждом шаге.

## Структура

```
src/lib/prompts/v8.ts        конституция и промпты шагов (сид версии v8)
src/lib/prompts/library.ts   структуры драматургии и типы хуков
src/lib/pipeline/            шаги, парсеры, кодовые гейты, сборка пакета
src/lib/server/              контекст промпта, репозиторий, сервис конвейера
src/lib/integrations/        Claude API, статусы интеграций, демо-генератор
src/db/                      схема Drizzle, bootstrap SQL, сиды
src/app/                     интерфейс (Next.js App Router) и server actions
tests/                       node:test
```
